- ## Listas
  heading:: 2
  É uma sequência ou coleção ordenada de valores. Listas são similates a **tuplas**, mas, diferentemente das **tuplas**, as listas são ==mutáveis==. Para criar uma lista, apresentamos seus elementos entre colchetes ==[ ]==.
  *Exemplo 1. listanum = [1, 2 , 3, 4]*
  
  **Fatiamento de listas**
  + **[start : end]** - vai do índice start até o índice end;
  + **[start : ]** - vai do índice start até o final da lista;
  + **[ : end]** - vai do início da lista até índice end;
  + **[ : ]** - copia a lista toda.
- ## Dicionários
  heading:: 2
  São usados para *coleções não ordenadas*. *Coleções não ordenadas* não pressupõem ordem entre seus elemntos, logo o conceito de índices de acesso não se aplica a elas. Os dicionários são delimitados por chaves =={ }==. Dicionários são ==mutáveis==.
